# Himanshu Agrawal - Professional Portfolio

A high-performance, visually immersive personal portfolio website designed for a Software & Automation Engineer. 

This project features a "True Black" aesthetic with an interactive "Neural Constellation" background, 3D animations, and a responsive glassmorphism UI.

## 🚀 Features

*   **Interactive Neural Background**: A custom Canvas-based particle network that reacts to mouse movement, symbolizing connection and logic.
*   **Cosmic/Northern Lights Theme**: Deep black backgrounds with dynamic Aurora Borealis gradients (Emerald Green & Royal Blue).
*   **Glassmorphism UI**: Modern, translucent cards with blur effects for a premium feel.
*   **Animations**: Smooth entry animations, hover zoom effects, and scroll-driven interactions using `Framer Motion`.
*   **Responsive Design**: Fully optimized for mobile, tablet, and desktop views.

## 🛠️ Tech Stack

*   **React 18**: UI Library.
*   **TypeScript**: Type safety and logic.
*   **Tailwind CSS**: Styling and responsive design system.
*   **Framer Motion**: Advanced animations and gestures.
*   **Lucide React**: Modern iconography.
*   **HTML5 Canvas**: Custom background rendering.

## 📦 Installation & Local Development

1.  **Clone the repository**
    ```bash
    git clone https://github.com/your-username/your-repo-name.git
    cd your-repo-name
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Run Development Server**
    ```bash
    npm run dev
    # or
    npm start
    ```

4.  **Build for Production**
    ```bash
    npm run build
    ```

## 🌍 Deployment (Vercel)

This project is optimized for deployment on [Vercel](https://vercel.com).

1.  Push your code to a GitHub repository.
2.  Log in to Vercel and click **Add New Project**.
3.  Import your GitHub repository.
4.  Vercel will detect the framework (Vite/React).
5.  Click **Deploy**.

## 🎨 Customization

*   **Colors**: Modify `tailwind.config.js` to change the `aurora` color palette.
*   **Data**: Update `constants.tsx` to change text content, experience, and projects.
*   **Particles**: Adjust physics settings in `App.tsx` (particle count, connection distance).
